# 飛鵝 58mm 便當小票

日期：2026-11-01

## 版型與資料

- 店名、單據種類與實際六碼取餐碼置中；顧客、取餐時間、餐點、付款狀態與總額提高辨識度。
- 聯絡方式只保留一項：訂單收件電話，其次本人基本資料手機；都沒有時使用訂單的聯絡 Email。不是發票 Email，也不從 LINE 推測手機。
- 訂購、取餐與送印時間使用台灣時間。送印時間指首次送印嘗試的伺服器時間，並非硬體出紙時間；未送出的後台預覽顯示「送印時產生」。
- 品項、客製選項、餐具、取餐點／地址、備註、數量與金額仍來自原訂單。若品項小計與訂單總額不同，分列小計與金額調整。
- 付款狀態於首次送印封存。LINE Pay 僅在同訂單版本、相符金額、未被替代且已成功的雷門付款紀錄確認 `PaymentType=linepay` 時顯示；其餘未知線上方式保留「線上付款」。現場收款按已確認紀錄區分現金、POS 與掃碼，不把掃碼推定為 LINE Pay。

## 歷史與重試

首次送印在取得 lease 的交易內封存付款、送印時間與完整內容，再呼叫雲端 API；安全重試沿用同一份內容，不會悄悄更新日期或付款資訊。原單、數量修訂、取消通知及明確補印各自保留種類與版本，新工作取得自己的送印時間。改量／補印不重新查詢最新個人資料，以免污染既有顧客聯絡快照。

電話快照及含電話的收據內容沿用版本化 AES-256-GCM 加密，分別以訂單 ID 的不同 AAD 綁定；只在送印／管理員預覽時於記憶體解密，不新增電話明文副本。既有密文損壞或資料金鑰失效會阻擋送出，顯示可讀錯誤；不回退為明文保存，也不反覆重送。原有無電話的純文字收據保留相容讀取。

舊快照缺少聯絡資料時仍可列印，不能捏造聯絡方式或訂購時間。後台純文字預覽移除受控排版標籤，不使用 HTML 插入。顧客輸入中的控制符號與標籤仍會清理。

## 硬體與格式

依[飛鵝官方小票 API](https://help.feieyun.com/#/home/doc/zh;nav=1-1)及[官方標籤說明](https://www.feieyun.com/open/apidoc-cn.html)：`CB` 置中放大、`C` 置中、`L` 倍高、`BOLD` 加粗、`RIGHT` 靠右、`BR` 換行。倍高仍保留原行寬，倍寬標題先以半行寬斷行。

[FP-V58-W](https://www.feieyun.com/product_detail-V58W.html) 普通字每行 32 英數格／16 中文字；本機無切刀，不送 `CUT`。整張內容含標籤仍受 5000 UTF-8 bytes 上限保護。

## 驗收範圍

隔離測試包含電話／Email 來源、加密失效回退、台灣跨日時間、付款通道辨識、提交前內容已持久化、安全重試、補印／改量／取消、新舊快照、字寬、標籤清理及預覽只讀。另保留 PostgreSQL 訂單修訂與履約並行測試。

預覽與測試僅使用虛構資料，沒有建立正式交易。硬體字體、實際換行與收據張數仍須用一張新的版型測試核對；舊版單張 API 測試成功不能當作本版實印驗收。首筆真實訂單至自動出紙仍是獨立的完整流程驗收。
