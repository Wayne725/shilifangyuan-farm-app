# 管理員以手機核對社員

日期：2026-11-06

## 需求與操作

會員管理的「線下確認並設為社員／核對並恢復社員資格」，改以手機號碼核對既有社員名冊，移除手填社員編號。

1. 管理員在目標網站帳號輸入手機，按「核對手機」。
2. 顯示唯一符合名冊的姓名、原社員編號及遮罩手機，這一步不授予會籍。
3. 管理員核對本人與線下入社／繳費資料，填日期及理由，再確認授予。
4. 最終提交重新查核手機與名冊；沿用原社員編號、股號、股數與股金。

手機支援既有正規化規則：全形、空白、橫線及 +886。更改輸入會清除先前核對結果與勾選；過期的查詢回覆不能啟用確認按鈕。

## 阻擋與相容範圍

- 查無名冊、同號多筆、停用、他人已認領或認領中，不授予資格，也不自動另編社員號。
- 已屬於本人的名冊可用於恢復會籍；重複送出不重複建會籍或審計紀錄。
- 既有社員編號與股籍衝突、線上收退款、退出／終止會籍、新版入社流程保護維持。
- 不變更公開 LINE／Email 社員認領流程；此功能是管理員人工核對，不是簡訊驗證。
- 不寫入明文手機至審計紀錄，不產生線上付款。
- 舊前端若仍傳 `member_number`，須重新整理後使用手機核對；後端不接受舊的授予格式。

## 驗證

後端驗證涵蓋手機格式、唯一名冊、預覽不寫入、提交重新查核、股籍保留、會籍恢復、權限與收退款保護。PostgreSQL 驗證兩帳號競爭同一名冊及原付款／退款鎖序。

隔離瀏覽器驗證手機與桌機：核對與確認分步、改手機失效、延遲舊回覆、錯誤不授權及非管理員無入口。正式環境僅驗收介面與唯讀查核，不更動真人會籍。
