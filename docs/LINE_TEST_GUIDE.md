# LINE 測試操作

日期：2026-10-22

從 LINE 官方帳號「十里方圓(測試版)」的下方選單開始。

## 非社員

1. 點「非社員登入」。
2. 選「使用 LINE 註冊」，閱讀並勾選資料使用同意。
3. 按「使用LINE登入」，依 LINE 畫面完成授權。
4. 返回訂餐網站；確認顯示自己的 LINE 名稱，重新整理仍保持登入。

## 既有社員

1. 點「社員登入」。
2. 輸入合作社名冊上的電話號碼與 Email，再按「繼續使用 LINE」。
3. 完成資料同意及 LINE 授權。
4. 到原信箱收取驗證碼，在網站驗證後確認社員資格。

電話與 Email 必須能對應同一筆有效名冊。已有網站帳號或已認領者，使用「已有帳號？直接登入」；已有 Email 帳號欲綁 LINE，先登入原帳號，再於帳號中心連結。

## 便當現場付款

管理員先在欲測試的便當場次勾選「開放合作社現場付款」。買家選餐時選現場付款；工作人員實際收款並核對後，再由後台標記已付款。誤標更正必填原因；發票由合作社 POS 開立。

本次 LINE 登入測試可停在訂餐頁，無須建立付款交易。實體出單驗收另見 [飛鵝整合](FEIE_PRINTING.md)。
