# 入社流程整合狀態

日期：2026-10-29

## 已確認範圍

本次先開放「基本資料與入社志願書 → 指定版本教材與閱讀確認 → 10題測驗達80分 → 管理員正式審核」。不收身分證字號或證件，不新增個人網站／Facebook欄位。繳費、銀行核帳及發證仍待確認，因此本階段不建立會籍、應收、付款或通知工作。

學生資格由管理員核驗；每股100元，學生認購5–10股、一般10–100股。入社費預設500元，管理員可在「會員社務 → 社務管理 → 入社教育」調整新申請的入社費。申請沿用建立當時的金額，送審留存當輪金額與股金，本階段不收取。管理員設定額外重考次數與間隔；未設定時只允許首次作答。

## 新流程

- `/membership`：四步驟入社申請。閱讀採本人確認，不宣稱已追蹤完整投影片瀏覽時間。
- `/membership/legacy`：唯讀舊版入社紀錄與歷史款項入口，不改寫舊申請。
- `/admin/social`：獨立入社教育審核區，提供狀態、姓名／Email查詢、分頁、成績、版本及正式決議紀錄。核准學生須明確核驗資格。
- `/admin/settings`：重考次數與間隔，版本衝突保留草稿，重新讀取後才可儲存。
- 補件沿用同輪作答及成績；撤回或駁回後重新申請建立新輪，重新閱讀、同意及測驗。每次送件保存不可覆寫的個資與規則快照。
- 新申請歷史阻擋舊版授予會籍、建應收與轉正旁路。名冊認領仍可確認既有社員；歷史付款回報保留實收，不因新流程回滾交易。

3. [合作社個資聲明](https://www.coop4sustainability.live/post/有限責任臺灣城鄉永續生活消費合作社個人資料聲明同意書)已透過瀏覽器核對可讀，更新日期2023-12-18；本網站依本次決議不收字號，即使原聲明列有字號項目。

## 尚未開放

- 審核同意通知及正式的繳費通知內容、發送時機。
- 入社費／股金應收快照、銀行轉帳實收、差額分配及核帳。
- 核帳後正式入社、股號股數異動與社員證／股票產製、私有調閱及寄送。
- 正式證書範本、編號規則及章授權等營運設定。

第20項仍屬「待補功能」；第一階段完成不代表完整入社已全部完成。原需求表驗收欄保持原值。不可為了開放審核而把正式sales_scope改成all。

## 資料與升版

新增0040遷移只建立獨立申請輪次、測驗、送件及審核表，不轉換歷史案件。個資按輪次與送件版本分別加密；本人及管理員以外無法讀取，私密回應no-store。降版遇到既有新紀錄會中止，避免刪除歷程。

教材、聲明、題庫未來變更須保留歷史版本解析及舊輪規則，不可單純覆寫常數。後續政策、收款與發證應依本輪審核結果接續，詳見[架構決策](adr/0002-versioned-admission-rounds.md)。
