## 本輪 UI 修正

正式 `sales_scope=pickup` 僅開放便當及商品自取。舊入社核准路由會同時建立會籍及入社費／股金應收，故被既有交易限制擋下；不移除防護，也不將 scope 改成 all。後台先依平台狀態停用入社核准，提示入社專用阻擋原因；平台狀態讀取失敗或缺少 scope 時也不啟用。補件、駁回、既有社員認領與歷史查詢維持原行為。

前台移除先付款再審核的過時敘述；完整進度說明集中常見問題。這不是完整入社開放。
