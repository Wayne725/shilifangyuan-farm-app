# 操作介面層級與訂餐首屏改善

日期：2026-10-21

基準：已發布提交 `7adfd14`；本輪沿用 Vite／React 前端及既有品牌字體、米色、深綠、金色中英小標，保留餐點照片尺寸與份數按鈕。

## 調整

1. **首屏內容**：字級選擇移到頁首的「Aa 字級」，保留標準／放大及偏好儲存。選餐頁合併重複標題、改為緊湊取餐摘要，縮短頁首留白。後台減少重複管理者資訊與導覽間距，1280×720 能看到搜尋及第一筆訂單狀態。
2. **後台導覽**：工作台主分類以深綠底選取，第二層保留細線頁籤，第三層改為緊湊文字導覽。手機分類在同一列水平捲動，避免「設定」單獨換行；導覽名稱與授權條件不變。
3. **文字對比**：金色色階調為 `#806032`，保留金色方向；必要的一般文字達到至少 4.5:1，瀏覽器測試以實際樣式計算。
4. **訂單狀態**：一般訂單營運及便當訂單查詢共用 `OrderStatusBadge`，依待處理、處理中、完成、異常及中性狀態呈現文字與圖示。尚未符合開票條件是中性，退款／取消／作廢完成降低視覺權重。
5. **取餐日期**：目前只有明天可預訂，改顯示日期摘要及可選時段，移除沒有其他日期可選的大型日期按鈕；午夜後仍依台灣時間重新推導明日，預訂規則不變。
6. **付款確認區**：優惠碼預設收合；有效的發票設定顯示摘要及修改入口，缺少或無效資料直接展開。編輯中的有效輸入不會自動收合。合計緊接付款按鈕，清空移到下方並降低權重。取餐時間、Email、發票選項、優惠碼、報價及付款送出條件沿用既有資料流程。
