# FP-V58-W 雲端站點設定調查

日期：2026-10-31

## 調查結論

**目前已確認這台 FP-V58-W 在中國站正常在線，且成功印出一張繁體中文測試單；具體處理路徑是讓網站正式支援中國站（CN），無須先遷移硬體雲站。** 同 SN 核對與送印由主代理實測，實際出紙及繁中字形由使用者確認，詳見下節。JP 仍 Offline，待印 4 筆未清除、未重送，來源仍未知。

官方文件研究確認飛鵝有中國、亞太（JP）、歐洲三站，但未找到適用本機的公開遷往 JP 操作步驟。APP 與公開設備編輯 API 沒有列出雲區域設定；這項研究保留為歷史界線，原廠查詢已不是目前完成出單的主要阻塞。[亞太接入文件](https://feieyun.com/open/AsiaPacific-cn.html)、[2026 API 分流公告](https://help1.feieyun.com/docs/96C8PyrC)、[APP 配網教程](https://help1.feieyun.com/docs/8rBDwn)

本研究子任務只讀取官方公開資料及更新本文件；下節另記錄主代理與使用者完成的現場驗證，兩者分開標示。文件不收錄 SN、設備 KEY、開發者 USER／UKEY 或 Wi-Fi 密碼。

## 公開改站途徑的歷史調查

1. **帳號側選站：**官方亞太文件可直接導向 JP 後台；這台已完成新增，應保留現有證據，不能把重新新增或跨站反覆綁定當作官方遷移流程。[官方接入流程](https://feieyun.com/open/AsiaPacific-cn.html)
2. **網路側配置：**公開 APP 的作用是將 SSID／密碼交給打印機；本機已播報聯網成功，沒有證據支持繼續重跑配網能改變雲站。[APP 教程](https://help1.feieyun.com/docs/8rBDwn)
3. **設備側改站／海外開通：**已查到的官方公開來源沒有說明某 SN 如何指定 JP、是否有出廠限定、官方客服遷移或專用韌體條件。若之後另有遷移到 JP 的需求，再請飛鵝依 SN 與模組提供具體流程；目前已有中國站實印結果，不需要等待此文件才能推進網站 CN 支援。

### 舊網頁配網頁的「模式切換」不是雲站

已從官方 V58 Wi-Fi 目錄取得舊教程實際連結 `hskwy`，並唯讀檢視其長圖。它的適用說明為帶 Wi-Fi 的紅色 FP-V58；畫面導覽只有「系統信息／WiFi配置／模式切換」。步驟先設定 SSID／密碼，儲存後返回，再到「模式切換」選 **STA 模式**，最後重啟。這是 Wi-Fi 連線模式，不是中國／亞太／歐洲站選擇。圖中的 `10.10.100.254` 不應因與新模組 IP 一樣就被當作通用的改站入口。[官方舊教程](https://help1.feieyun.com/docs/hskwy)、[教程原圖](https://resource-wangsu.helplook.net/docker_production/r17y0v/article/QtFtLi/654e11dc87a07.jpg)

本機已聯網，此研究沒有指示進入網頁配網模式或改動 STA/AP；即使之後必須查本機設定，也應先匹配實機小票、模組與官方指南。
