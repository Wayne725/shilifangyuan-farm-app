# 便當使用者操作手冊

日期：2026-10-13

本手冊對應本次便當功能更新。所有日期與時間都使用台灣時間。

## 1. 登入與社員身分

1. 已有 Email 帳號時，先登入原帳號，再到帳號中心按「連結LINE」，保留原訂單與社員資格。LINE 授權完成後回到帳號中心確認「已連結LINE」。
2. 新使用者開啟登入入口，依實際資格選「我是社員」或「我不是社員」，再按「使用LINE登入」。首次註冊選「我是社員」者會接續認領既有社員資格；選「我不是社員」者回原頁。社員資格須經核對才生效。
3. 依 LINE 畫面完成授權；若要求手機驗證，使用自己的 LINE App 完成。首次使用需填一次通知信箱，之後可直接使用 LINE 登入，不需另外建立密碼。
4. 登入視窗只提供一個「保持登入」：控制登入工作階段，使用 Email 登入時也預填信箱。網站不保存 LINE 或 Email 明文密碼。共用裝置請取消保持登入，使用完畢登出。
5. 登入後可查看自己的訂單。已在線下繳交社員費用但身分尚未更新時，請聯絡管理員核對。授權取消或 LINE 暫時無法使用時，可沿用 Email 登入。

正式站已成功完成 LINE 授權、既有帳號連結、登出後以 LINE 重新登入及重整恢復登入。新使用者補填 Email 尚待實際使用者驗收，詳見 [LINE 設定與驗收](LINE_LOGIN_SETUP.md)。

## 2. 預訂明天的便當

1. 開啟「我要訂餐」。畫面只提供明天的取餐日期，不能訂今天或後天以後的餐點。
2. 在取餐地點下直接選半小時時段，例如 11:30 或 17:00。無須先選午餐或晚餐；選好的時間會帶入訂餐頁。
3. 確認取餐日期和地點。餐點以條列呈現，按 `＋` 增加份數，按 `－` 減少份數。
4. 若餐點有必選項目，依提示完成。例如主食必選一項。
5. 核對已選的取餐時間，需要調整時可按時間按鈕，或「更換取餐時間」返回完整時段：午餐 11:00、11:30、12:00、12:30、13:00；晚餐 16:30、17:00、17:30、18:00。實際開放按鈕依該場次的取餐窗口決定。
6. 確認電子發票資料。一般個人發票會預填登入 Email；需要公司統編或手機條碼時再調整。
7. 在「確認訂單明細」核對餐點、份數、客製選項、預計取餐時間、發票資料和合計金額。
8. 按「預訂並前往線上付款」，依付款頁指示完成。

場次可能提早截單，請依畫面「預訂截止」時間送出；最晚只能在取餐日前一天結束前預訂。便當採現場取餐，訂餐流程不選配送或物流。

## 3. 返回繼續選餐

同一個瀏覽器分頁離開再返回時，會保留餐點、份數及取餐時間。系統會用最新菜單、庫存及時段重新檢查，發生調整會提示。

跨到取餐當天後，該日不能再建立新訂單。訂單成立後會清除該場次草稿；需要查看已成立訂單時，請使用「我的便當訂單」，不要重新選餐。

## 4. 查看訂單與完成取餐

1. 開啟「我的便當訂單」，登入同一下單帳號。
2. 依取餐日期及餐別選擇訂單。
3. 明細包含唯一訂單編號、餐點、數量、單價、小計、付款狀態、地點及預計取餐時間。
4. 付款確認成功後，畫面提供 QR 與六位取餐碼。
5. 到指定地點出示 QR，或告知六位取餐碼。
6. 現場人員核銷後，這組取餐碼失效，避免重複領餐。

付款中斷時，先查看原訂單狀態。若仍可付款，使用原訂單的「前往付款」；不要為了發票尚未開立再付款一次。

## 5. 申請取消或退單

1. 在「我的便當訂單」開啟需要取消的訂單。
2. 若狀態允許，按「申請取消這筆便當」。
3. 填寫原因，按「送出退單申請」。
4. 查看「退單申請待審核」及管理員後續回覆。

送出申請不會直接取消。管理員核准前，訂單仍有效；核准後才取消整筆訂單並依付款狀態安排退款。拒絕申請時，原訂單繼續依目前狀態處理，理由會顯示在明細。

退款、發票作廢與取餐狀態分開顯示；核准不代表退款已入帳。已取餐或供餐結束等例外狀況，需要聯絡管理員。目前沒有自行修改取餐時間或部分退單入口。

## 6. 發票與常見問題

電子發票會在後端確認付款成功後處理，票號與開立時間可在訂單明細查看。已付款但發票尚未開立時，只要取餐碼有效，仍可依預約取餐。

「常見問題」入口包含 LINE 註冊、訂餐、截止時間、付款中斷、忘記訂單編號、退單、社員身分及逾時未取等常見問題，可由電腦或手機的三條線選單進入，逐題展開閱讀。

## 7. 給不熟悉手機操作的使用者

- 先確認明天日期與取餐地點，再點時間，接著選餐點與份數。
- 網站上方「標準／放大」按鈕可切換字體；選擇會記在目前瀏覽器，重整或返回仍套用。
- 功能小標題與說明最低為 16px，放大模式至少 20px；主要操作項目至少 48px 高；取餐時間使用大按鈕直接點選。
- 手機畫面下方的「查看明細」可直接跳到已選餐點與金額。
- 出現庫存或時段調整提示時，先重新核對再付款。
- 需要協助時，提供訂單編號即可，不需要提供 LINE 密碼。
