# 入社教育與審核採獨立申請輪次

日期：2026-10-29

新入社案件採獨立版本化輪次，保存加密個資快照、同意版本、教材確認、測驗作答、送件修訂及審核決議。補件沿用同輪；撤回或駁回後新申請不沿用舊成績。第一階段僅到審核，不建立會籍、應收、通知或憑證。

## Considered Options

- 延伸舊版單一申請：原有核准會建立會籍與應收，覆寫原資料會混淆真實歷史收款及新教育流程。
- 直接搬移所有舊案：需要先確認歷史款項與會籍政策，超出本次已確認範圍。
- 獨立輪次與不可變送件紀錄：保留歷史語意，並以後端防護阻止新案經舊路徑繞過教育與審核，採此方案。

## Consequences

- 同一使用者的寫入固定先鎖使用者再鎖輪次，搭配版本檢查及交卷冪等鍵，避免同時交卷或相互覆蓋決議。
- 舊版資料保留唯讀入口；既有社員名冊認領維持獨立的身分核驗途徑。歷史金流回報仍保存實收，不因新輪次而丟失交易。
- 後續繳費、銀行核帳與發證必須依本輪核准資料另行接續，不能將審核狀態直接當成社員資格。
