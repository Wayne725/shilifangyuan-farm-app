# 手機購物與後台查詢修正

日期：2026-10-27
基準：e7e0967；本輪不包含尚未完成的入社教育流程。

## 需求與結果

| 項目 | 調整 |
| --- | --- |
| 電腦 LINE 登入回首頁 | 正式網站實際登入成功，使用者亦確認顯示名字；原因為 return_to=/。LINE 此入口改回會員中心，/shop 官方選單、結帳與餐點返回路徑保留。 |
| 廚房出單 UI | 列印搜尋與狀態對齊；查詢／清除和設備／說明分組，手機單欄。 |
| 便當取餐安排 | 日期、時間、取餐點、餐具集中於確認訂單明細，移除左側與摘要重複資訊。 |
| 商品加入數量 | 保留數量下拉，原＋改成明確加入購物車；大量模式只顯示一個數字輸入。 |
| 儲存載具 | 新增預設未勾選的儲存選項；輸入不儲存，勾選後結帳才保存。未勾選仍可用於當次發票，原已存載具不被刪除，保留明確移除操作。 |
| 訂單彙整入口 | 後台各頁顯示訂單彙整捷徑，統一名稱，保留一般／便當分類與查詢。 |

## 衝突檢查與驗證

- 修正 UI-only saveCarrier 影響便當送單指紋的衝突，保持舊版冪等重試識別；未變更後端訂單 schema。
- 100 個 Node 測試通過；163 個相關後端測試通過；TypeScript 與 Vite build 通過。
- 本機隔離 API + CUA 實測：390px 商品選3件不自動加入，按加入才加3、超庫存阻擋；一般結帳未勾選不 PATCH 載具、發票仍帶當次條碼；便當勾選後 PATCH 載具、時間／地點／餐具與主食正確送單；手機無頁面橫向溢出。
- CUA 實測 390px、899px 廚房版面；列印關鍵字／狀態查詢、彙整快捷入口、便當分類與一般訂單查無結果正常；本機 LINE 模擬回呼導向會員中心。
- 既有 browser 測試檔已同步新選項與名稱；本輪未執行外部 Playwright 套件，互動驗收使用 CUA。
- 本機模擬付款只到隔離頁，未建立正式訂單、扣款、退款或變更正式會員載具。
- 發布與正式站復核結果另記工作區 outputs 的需求進度及本輪驗收紀錄。
