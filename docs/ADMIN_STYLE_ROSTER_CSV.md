# 後台風格統一與 CSV 社員名冊

日期：2026-10-10

基底：正式前後端版本 `e3117353f4a50cc587c1e1a963495247b0286f25`。

## 畫面調整

- 以商品供應既有 `.tab-list` 為基準，訂單營運四個子頁面共用透明底、底線選取樣式；桌機置中等寬，手機可在頁籤列橫向滑動。
- 營運內容移除單側最大寬度限制，與頁籤沿用共同頁面邊界。
- 管理工作台分類字級、垂直對齊統一；查詢參數不再使目前工作台失去選取標示。
- 便當預購、訂單、FAQ 的大字規則排除 `.eyebrow`，財務與廚房移除放大小標題的覆寫。保留原有色彩、襯線標題和正文可讀性。
- 便當預訂、午晚餐時段、退單審核、付款／發票、股籍編輯與廚房功能維持原有資料流程。

## CSV 名冊

逐筆新增介面改為選 CSV → 預覽／查重 → 確認整批匯入。UTF-8 BOM、UTF-8、Big5，最多 500 筆與 2 MB；必填社員編號、姓名、Email、手機，股金／股數選填。

預覽唯讀；提交時再驗證格式、重複和最新名冊／會籍。單一交易保存所有紀錄及一筆稽核，唯一約束衝突時全部回退。沿用個資加密，不自動建立帳號、修改會籍或產生金融交易。匯入不覆蓋已有編號，不支援的欄位明確拒絕。

新端點：`POST /v1/admin/member-roster/import/preview`、`POST /v1/admin/member-roster/import`，均限管理員。無新增資料庫遷移、第三方套件或雲端設定。

操作步驟與欄位限制見 [管理員手冊](MEAL_ADMIN_MANUAL.md)。
