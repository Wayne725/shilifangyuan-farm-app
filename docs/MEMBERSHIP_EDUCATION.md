# 入社教育與重考

日期：2026-10-29

10題每題10分，80分合格，合格只適用同一申請輪次；補件保留同輪成績及已用次數，撤回或駁回後的新輪重新測驗。公開題庫沒有答案鍵，交卷由後端評分後回傳本次逐題結果。

後台「設定」的入社教育表單可設定額外重考次數（不含首次）及間隔分鐘。0次僅能首次作答；間隔0分鐘不用等待。尚未配置時欄位留白，只允許首次。設定與接單、客服、設備分開保存，附原因、版本與稽核。次數範圍0–100、分鐘0–525600，嚴格拒絕布林、字串、小數與負數。

GET/PUT `/v1/admin/membership-education/settings`限管理員。每次交卷保存當時設定版本；管理員調整不會歸零已用次數。交卷先鎖使用者再鎖輪次，版本檢查及同一冪等鍵避免重複消耗；同鍵不同答案回409。間隔未到不消耗次數，合格不能再考。

介面背景刷新不覆蓋草稿；版本衝突後保留內容並要求明確重讀。入社資料、教材、測驗與審核已接成獨立第一階段，繳費、核帳與發證待確認。詳見[整合狀態](MEMBERSHIP_ADMISSION_STATUS.md)及[第一階段API](MEMBERSHIP_ADMISSION_PHASE_ONE_API.md)。
