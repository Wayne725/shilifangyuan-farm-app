# 網站導覽與 LINE 新註冊分流

電腦及手機共用三條線選單，包含首頁、生活消費、結帳、已登入者的訂單與會員中心、常見問題、登入／登出；管理員另有管理工作台。電腦保留首頁／生活消費／社務系統的圓角導覽，以及右側訂單、結帳、帳號操作。中小型電腦縮為品牌圖示，避免放大字體時互相擠壓。

社務系統的導覽、首頁入口與活動預覽，只顯示給正式社員及管理員。非社員、實習社員、停權社員與訪客不顯示這些入口；社務頁仍保留既有資格與 API 權限核對。判斷使用後端登入資料的 membership_type／membership_status，並同步會員中心已取得的最新 membership-me 快取。註冊意向不作為權限依據；導覽本身不額外查詢私人資料。

字體控制保留「標準／放大」與讀屏所需的「文字大小」群組標籤，移除畫面上的「字體大小」。選擇仍存於目前瀏覽器。「需要幫忙」與頁尾說明入口統一為「常見問題」。

## LINE 新帳號

1. 進入網站並開啟帳號登入，選社員意向，按使用 LINE 登入。
2. 新身分授權成功後補一次通知 Email；不需另外建立網站密碼。
3. 首次建立帳號選「我是社員」者，到會員中心的既有社員資格認領。認領或管理員核對前仍為非社員，不能讀取社員資料。
4. 首次建立帳號選「我不是社員」者，回到原來的訂餐等頁面。
5. 已存在的 LINE 身分維持原帳號與原頁返回。已有 Email 帳號須先登入該帳號，再連結 LINE；相同 Email 不自動合併。
