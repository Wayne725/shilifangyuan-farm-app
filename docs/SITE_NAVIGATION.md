# 網站導覽與 LINE 新註冊分流

管理後台的「訂單營運」子選單在「訂單、付款與發票」後提供「訂單匯總」，連至 `/admin?section=summary`，可依日期、銷售類型、狀態、品類及品項名稱查詢數量。統計口徑見 [訂單匯總](ORDER_SUMMARY.md)。

電腦及手機共用三條線選單，包含首頁、生活消費、永續活動、社務系統、結帳、已登入者的訂單與會員中心、常見問題、登入／登出；管理員另有管理工作台。電腦保留首頁／生活消費／永續活動／社務系統的圓角導覽，以及右側訂單、結帳、帳號操作。中小型電腦縮為品牌與操作圖示，並保留讀屏名稱，避免放大字體時互相擠壓。

「永續活動」位於「生活消費」旁，連至既有 `/activities`。活動頁、社務分頁與首頁活動資訊共用新名稱；活動內容、發起與報名仍依既有登入及社員資格核對。

生活消費頁的分類列也在「日常選品」後提供「永續活動」連結，直接前往 `/activities`。原有三種消費分頁保留分頁切換與方向鍵操作；活動使用一般連結，可用 Tab 鍵聚焦。窄螢幕可橫向滑動整排入口。

首頁介紹區在「進入生活消費」旁提供「永續活動」與「加入合作社」按鈕，分別連至 `/activities` 及既有 `/membership` 入社申請。訪客可由入社頁登入後返回繼續申請；一般會員可填寫資料或查看申請進度，正式社員則顯示既有社員資格。

頂部圓角導覽的社務按鈕、首頁入口與活動預覽，只顯示給正式社員及管理員。三條線選單中的「社務系統」則對所有人保留；訪客點入後可登入，非社員可查看入社入口，社員內容仍受既有資格與 API 權限核對保護。頂部入口判斷使用後端登入資料的 membership_type／membership_status，並同步會員中心已取得的最新 membership-me 快取。註冊意向不作為權限依據；導覽本身不額外查詢私人資料。

字體控制保留「標準／放大」與讀屏所需的「文字大小」群組標籤，移除畫面上的「字體大小」。選擇仍存於目前瀏覽器。「常見問題」入口集中在三條線選單，頁面及頁尾不重複顯示。

生活消費頁的標題依便當預購、共同購買、日常選品同步顯示「我要訂餐」、「共同購買」、「日常選品」；「我的便當訂單」按鈕只在便當預購顯示。便當訂單頁的返回連結與主標題保留間距，放大字體時一起調整。

帳號登入使用獨立的 `/login` 頁面，Email 與密碼為主要表單，社員意向和 LINE 登入放在下方；保留單一「保持登入」。登入成功返回原本的站內頁面及查詢參數，拒絕站外返回網址。說明頁移除訂餐捷徑與固定回便當的連結，統一回到首頁。

## LINE 新帳號

1. 進入網站並開啟帳號登入，選社員意向，按使用 LINE 登入。
2. 新身分授權成功後自動建立顧客帳號並回到原頁，不需 Email 或網站密碼。
3. 「我是社員／我不是社員」只記錄意向，均不會中斷訂餐；社員資格由管理員另核對名冊，不自動授權。
4. 結帳時填訂單與發票通知信箱；成立訂單後保存為下次預填，不改動登入 Email、不當成 Email 驗證或合併帳號的依據。
5. 已存在的 LINE 身分維持原帳號與原頁返回。已有 Email 帳號須先登入該帳號，再連結 LINE；相同 Email 不自動合併。
