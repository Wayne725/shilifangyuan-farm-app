# 共同購買截止審核發布檢查

日期：2026-10-25

本版增加 0037 遷移：舊已確認承諾與所有終態保留；未截止有效團恢復持續集單，審核預設截止後 72 小時；已截止有效團進付款核對並給一次審核寬限。付款截止與取貨承諾不改，衝突記錄於 AdminAudit；已存在明確取消／拒絕證據的異常狀態按證據修復，不重新退款或通知。

有共同購買資料或新付款核對紀錄時拒絕有損降版。回退須先規劃資料庫備份還原與金流補查，不可直接執行舊 worker。

若未來部署時存在已截止非終態，禁止讓含自動退單邏輯的舊 API／worker 與 0037 資料同時執行；先停止舊實例及背景／排程工作，確認不再處理交易，完成遷移及新版啟動後再恢復服務。新增欄位相容並不代表狀態語意可滾動相容。
