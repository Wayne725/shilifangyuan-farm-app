# 十里方圓 v2｜約兩分鐘展示講稿

大家好，這個專案叫做「十里方圓」，是為臺灣城鄉永續生活消費合作社設計的跨平台 App。

【操作：首頁切換「生活消費｜社務系統」】

我們把需求分成兩個工作區。「生活消費」包含農產品、團購、便當預購、訂單與物流；「社務系統」處理入社、社員資料、活動與社員提案。兩邊會各自記住使用者最後停留的位置。

【操作：生活消費首頁，再切團購】

一般商品與團購使用相同尺寸的兩欄卡片，方便快速瀏覽。社員價不是由手機自行判斷，而是後端只依有效會籍重新計算。團購則另外顯示付款進度、成團門檻與截止時間；只有付款成功的數量才計入成團。

【操作：便當頁與待取餐訂單】

便當可以依學校或攤位建立單次場次，各品項有自己的預購容量。建立付款頁後保留十五分鐘，付款完成會產生六位取餐碼與 QR；工作人員掃描或輸入短碼核銷，重複核銷會被阻擋。

【操作：訂單中的配送中項目】

農產品和確認成團的團購也能選宅配或超商物流。系統會檢查同張訂單只能有一種溫層與一個地址，並串接綠界物流測試環境。因為 Stage 不會自動模擬後續貨態，管理後台另外提供有稽核紀錄的 Sandbox 推進按鈕。

【操作：切到社務系統】

非社員可以註冊、驗證 Email、填寫入社資料，再上傳三份測試證件。這裡明確禁止真實證件；檔案使用 Cloudflare R2 私有儲存，個資以 AES-GCM 加密。管理員核准後，申請人分別繳交示範入社費與股金，兩筆都成功才啟用社員編號。

【操作：活動與社員提案】

有效社員可以發起活動，額滿後採先到先得候補，取消時自動遞補。社員治理提案與商品團購分開，採公開記名的贊成、反對、棄權；棄權計入最低投票人數，但贊成仍必須多於反對才會通過。

技術方面，前端使用 Expo SDK 57、React Native、TypeScript、Expo Router 與 TanStack Query，同一套程式支援 iOS、Android 和 Web。後端使用 Python FastAPI、SQLAlchemy、Alembic 與 PostgreSQL；付款、發票和物流使用綠界 Stage，重要信件使用 MailerSend。

目前所有外部服務都在 Sandbox，不動真實款項，也禁止上傳真實證件；但完整的資料模型、權限、狀態與稽核流程都已保留，之後可以再接合作社正式規則。謝謝大家。

## 建議操作順序

1. 在生活消費首頁展示共用商品卡與社員價。
2. 開啟團購，查看門檻與付款進度。
3. 開啟便當待取訂單，展示六位取餐碼。
4. 開啟配送中訂單，展示物流狀態。
5. 切到社務系統，展示補件進度、活動候補與公開記名票。
6. 進管理後台，展示社務與訂單物流模組。
