# 十里方圓 v2｜約兩分鐘展示講稿

大家好，這個專案叫做「十里方圓」，是為臺灣城鄉永續生活消費合作社設計的跨平台 App。

【操作：首頁切換「生活消費｜社務系統」】

我們把需求分成兩個工作區。「生活消費」包含農產品、團購、便當預購、訂單與物流；「社務系統」處理入社、社員資料、活動與社員提案。兩邊會各自記住使用者最後停留的位置。

【操作：生活消費首頁，再切團購】

一般商品與團購使用相同尺寸的兩欄卡片，方便快速瀏覽。社員價不是由手機自行判斷，而是後端依會籍重新計算；實習社員和正式社員都有社員價，但正式社員權限另外判斷。團購則顯示付款進度、成團門檻與截止時間，只有付款成功的數量才計入成團。

【操作：便當頁與待取餐訂單】

便當可以依學校或攤位建立單次場次，各品項有自己的預購容量。建立付款頁後保留十五分鐘，付款完成會產生六位取餐碼與 QR；工作人員掃描或輸入短碼核銷，重複核銷會被阻擋。

【操作：訂單中的配送中項目】

農產品和確認成團的團購也能選宅配或超商物流。系統會檢查同張訂單只能有一種溫層與一個地址，並串接綠界物流測試環境。Web 以及 development／production build 完成物流或付款後會自動回到訂單；Expo Go 則手動切回後重新查詢。因為 Stage 不會自動模擬後續貨態，管理後台另提供有稽核紀錄的 Sandbox 推進按鈕。

【操作：切到社務系統】

一般買家註冊並驗證 Email 後會先取得 `SLF-C` 編號，再填寫入社資料及上傳三份測試證件。申請送出即可繳入社費和股金，不必先等資料審核；兩款都成功便取得 `SLF-T` 實習社員編號與社員價。訓練、面試及確認在線下進行，管理員完成確認後才在後台手動核發另一組 `SLF` 正式社員編號。線上教育與測驗已停用。

【操作：活動與社員提案】

只有正式社員可以發起及報名社員活動、使用積點、願望、會議、結餘與治理功能；實習社員只有社員價及本人入社進度。活動額滿後採先到先得候補，取消時自動遞補。社員治理提案與商品團購分開，採公開記名的贊成、反對、棄權。

技術方面，前端使用 Expo SDK 57、React Native、TypeScript、Expo Router 與 TanStack Query，同一套程式支援 iOS、Android 和 Web。後端使用 Python FastAPI、SQLAlchemy、Alembic 與 PostgreSQL；付款、發票和物流使用綠界 Stage，重要信件優先使用 Resend，MailerSend 作為備援。

綠界付款、發票及物流都使用 Stage，不動真實款項，也禁止上傳真實證件；Email 則由 Resend 實際寄送，失敗時以 MailerSend 備援。完整的資料模型、權限、狀態與稽核流程都已保留，之後可以再接合作社正式規則。謝謝大家。

## 建議操作順序

1. 在生活消費首頁展示共用商品卡與社員價。
2. 開啟團購，查看門檻與付款進度。
3. 開啟便當待取訂單，展示六位取餐碼。
4. 開啟配送中訂單，展示物流狀態。
5. 切到社務系統，展示一般買家、實習社員及正式社員的權限差異。
6. 進管理後台，展示三類銷售比例、手動轉正式社員與訂單物流模組。
