# 十里方圓｜老師展示清單與兩分鐘講稿

## 展示前 5 分鐘

1. 在專案根目錄執行 `pnpm demo`。
2. 開啟 `http://127.0.0.1:4173`，確認首頁 Logo、商品圖片與導覽正常。
3. 使用 `member@shilifangyuan.tw`／`member123` 登入社員帳號。
4. 另開一個分頁，使用 `admin@shilifangyuan.tw`／`admin123` 登入管理員帳號。
5. 不示範實際付款、超商門市選擇、Email 寄送與證件上傳；這些需要外部服務憑證或合作社正式資料。

若便當顯示「逾時未取」、社務展示資料為空，需先由管理員執行一次本機展示資料重設。這會清除本機測試紀錄，不影響任何線上資料。

## 建議展示動線（約 5 分鐘）

1. 首頁：說明生活消費與社務系統共用同一身分。
2. 生活消費：商品 → 團購投票 → 便當場次 → 我的便當，展示社員價、成團門檻、取餐 QR。
3. 社務系統：社員首頁 → 願望 → 活動 → 治理 → 社員帳戶，展示股數、積點、徽章與結餘。
4. 管理工作台：商品與供應 → 團購 → 便當 → 訂單 → 財務 → 社務，說明前台資料都由後端管理。
5. 回到首頁收尾，不進入未設定憑證的外部付款或物流頁。

## 兩分鐘講稿

大家好，十里方圓是為臺灣城鄉永續生活消費合作社設計的響應式 Web 系統。

【首頁】生活消費整合農產品、團購、便當與訂單；社務系統整合入社、社員活動、提案、願望、積點與會議。桌機與手機使用同一套正式介面。

【商品與團購】後端會依下單當下的有效會籍重新計價，實習社員與正式社員可用社員價。團購只計入付款完成的數量，達標後由管理員確認成團。

【便當與訂單】每個場次和餐點都有獨立容量，付款後產生六位取餐碼與 QR；工作人員可掃描或輸入短碼核銷。農產品與確認成團的團購可選合作社取貨、宅配或超商物流。

【社務】現實中已是社員者可用合作社名冊直接認領帳號；非社員驗證 Email 後取得一般買家編號，也可另行提出入社申請。新申請者繳清入社費與股金後成為實習社員，線下流程完成再由管理員轉為正式社員。

【管理】後台可管理商品、供應者、取貨點、團購、便當場次、訂單、物流、退款與社務審核，並檢視一般買家、實習社員和正式社員的銷售比例及稅務報表。

技術上，前端使用 Vite、React、TypeScript、TanStack Router 與 Query；後端使用 FastAPI、SQLAlchemy、Alembic 與 PostgreSQL。付款、發票、物流與 Email 的程式介面已保留，正式服務要等合作社提供帳號與憑證後啟用。

目前版本已完成單一前端整合；正式營運仍須切換正式第三方合約、持久化資料庫、監控及個資政策。
