# 十里方圓 App｜約兩分鐘介紹講稿

大家好，我們的專案叫做「十里方圓」，是為臺灣城鄉永續生活消費合作社設計的農產品與共同購買 App。

【操作：以 Render Web 開啟首頁；手機可直接用瀏覽器展示】

使用者可以先瀏覽在地蔬果、米與雜糧、蛋品及加工品。登入後，系統會依社員或非社員身分顯示不同價格；真正結帳時，價格仍會由後端重新確認，避免只靠手機畫面判斷。

【操作：切換到團購】

這次新增的核心功能是共同購買。買家可以針對現有商品或合作社設定的組合發起投票，提案通過審核後，大家可以投票並填寫預估需要的數量。達到門檻後，由管理員確認供應、價格和取貨時間，再轉成正式團購。

【操作：開啟正式團購並加入】

正式團購會顯示社員價、一般價、最低成團數、已付款數量、供應上限和截止時間。買家選擇數量後先線上付款，只有付款成功的數量才會計入成團。未成團或管理員取消時，系統會同步處理退款狀態、釋放名額並發出通知。

【操作：切換訂單或管理後台】

一般訂單和團購訂單會分開管理，付款、備貨、可取貨、已取貨及電子發票也各有清楚狀態。管理員可以審核投票、開團、確認成團、管理商品與訂單，並公布最終取貨時間。

技術方面，前端使用 Expo SDK 57、React Native、TypeScript、Expo Router 和 TanStack Query，所以同一套程式可以支援 iOS、Android 與 Web。後端使用 Python FastAPI、SQLAlchemy 與 PostgreSQL，負責身分、價格、庫存、投票、訂單和狀態規則。

線上付款串接綠界 AIO 測試環境，電子發票使用綠界 B2C 測試 API，重要通知則透過 App 通知中心和 SendGrid Email 發送。Web、API 和資料庫規劃部署在 Render，並由 GitHub Actions 定期處理截止、退款、發票與通知工作。

這個版本可以完整展示從選購、共同購買、付款、管理到現場取貨的流程，也保留未來接正式社員資料庫與出貨規則的擴充空間。現場建議以 Web 為主，避免實體 iPhone 的 Expo Go 版本與 SDK 57 不相容。謝謝大家。

## 建議兩分鐘操作路徑

1. 社員登入並展示社員價。
2. 進入「團購」，開啟 9／10 的投票並投下第 10 票。
3. 開啟接近門檻的正式團購，展示付款入口與成團進度。
4. 進入訂單頁，切換一般訂單／團購訂單。
5. 進入管理後台，展示待審提案及待確認成團。
