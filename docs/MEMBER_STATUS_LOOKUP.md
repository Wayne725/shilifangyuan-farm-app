# 公開社員資格查詢

日期：2026-11-06

## 操作

LINE 登入頁新增「不確定是否是社員？查詢社員資格」，連到獨立查詢頁。使用者填入手機及入社時登記的 Email，結果寄到該 Email；不用社員編號、不建立帳號、不授予資格，也不保留名冊認領。

查詢不改變原本 LINE、Email 註冊或管理員核對流程。頁面上的返回登入與既有社員入口保留原返回目的地與保持登入選擇，手機與 Email 不放進網址。

## 查詢規則

- 唯一符合且有效、未認領的名冊：通知資料相符，可完成既有社員註冊與驗證。
- 已認領且帳號啟用、會籍有效、社員編號一致：通知已有正式社員資格，應使用原帳號登入。
- 尚在認領期限內：請使用者完成原本的 Email 驗證，不延長或清除認領期限。
- 會籍停用、退出、終止、未啟用、名冊停用、資料矛盾、多筆或查無：請使用者核對或聯絡合作社，不直接判定非社員。

## 資料與寄送

公開 `POST /v1/auth/member-lookup` 只驗證格式、限流及排入加密工作，一律回覆 202「查詢已受理，請查看填寫的 Email。」與 `Cache-Control: no-store`，不在公開回覆揭露姓名、社員編號或是否匹配。

IP 與正規化 Email 雜湊各限每小時 5 次。首次處理工作才讀取最新名冊與會籍，寄送前加密保存固定信件內容；後續重試沿用同一內容與寄送冪等鍵。手機及 Email 加密保存，成功或終止重試後清除；信件不附姓名、手機、社員號、股籍或帳號 ID。

目前沿用單程序限流，若增加 API 實例須一併使用共用限流儲存。正式驗收只確認入口與表單，不對未知或真實社員信箱寄測試信；寄送成功、失敗重試及狀態判定由隔離測試與模擬寄信供應商驗證。
