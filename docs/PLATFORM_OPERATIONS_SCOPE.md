# 平台營運功能補齊

日期：2026-10-16

## 已確認需求

- LINE 提供既有社員及非社員兩個入口。
- 註冊先選身分；既有社員先填姓名、社員編號、Email，再用 LINE 或 Email 建帳，依名冊與 Email 驗證授予資格。
- 台灣每日 20:00 停止接明天的便當訂單。
- 管理員可開放／暫停新訂單，既有訂單、取餐與後台仍可使用。
- 出單機品牌型號尚未提供，先準備設備管理與瀏覽器 80mm 列印，不宣稱實機連線驗收。
- 累積點數、便當退單統整、社員股籍資料匯出及入社費／股金收款資訊、紀錄與匯出。
- 參考圖黃色項目：訂單與補印、發票開立／查詢／設定、營收／銷售明細、平台設定、菜單編輯、設備管理、滿額折扣與優惠券促銷。
- 保留既有米色、深綠、黃色中英小標與字體；補充說明集中常見問題。

## 執行順序

1. 平台開關與 20:00 接單規則（後端強制，前端狀態一致）。
2. 社員／非社員註冊與 LINE 入口，沿用名冊驗證，禁止自選資格。
3. 社員、股籍、入社收款及退單統計／匯出，保留真實款項來源與稽核。
4. 整合既有訂單、菜單、營收、發票及點數入口，補齊設備管理與促銷功能。
5. 隔離測試、完整 CI、部署與正式站讀取驗證，更新手冊及 Obsidian。

## 驗證界線

不在正式站建立測試訂單、退單、退款、收款或發票；款項只根據已確認的金流結果或管理員明確登錄的線下收款紀錄。匯出檔供送審使用，不直接對外傳送社員個資。
