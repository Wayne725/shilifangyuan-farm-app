# 下拉選單與版面整理紀錄

| 頁面／區塊 | 修改前 | 修改後 |
| --- | --- | --- |
| 訂單營運 `/admin?section=orders` | 全部／一般／便當三個按鈕 | 「訂單分類」下拉，保留搜尋、付款狀態與分頁重設 |
| 訂單匯總 `/admin?section=summary` | 訂單分類按鈕列 | 分類下拉，清單與統計使用相同分類 |
| 問題回報 `/admin?section=issues` | 四個分類按鈕 | 分類下拉，包含「其他系統工作」，保留關鍵字查詢 |
| 財務報表 `/admin/finance` | 訂單分類按鈕列 | 分類下拉，保持報表與匯出條件一致 |
| 發票管理 `/admin/invoices` | 訂單分類按鈕列 | 分類下拉，保留發票狀態、日期、關鍵字與 CSV 匯出 |
| 會計格式匯出 `/admin/accounting` | 訂單分類按鈕列 | 分類下拉，保留原有格式、日期及明細來源選單 |
| 金流與發票對帳 `/admin/statements` | 訂單分類及對帳結果按鈕列 | 分別改「訂單分類」、「對帳結果」下拉，匯出沿用選定條件 |

| 廚房出單 `/admin/kitchen` | 全部、午餐、晚餐、舊場次四個按鈕 | 「備餐時段」下拉，與取餐日期排在同一列 |
| 便當管理「全部訂單」 | 快捷製作狀態按鈕與更多篩選內的履約狀態重複 | 移除重複列；「履約狀態」下拉放在主要查詢區，按查詢套用 |
| 便當管理「退單審核」 | 待審核、已核准、未核准、全部四個按鈕 | 「退單審核狀態」下拉併入搜尋列，切換仍立即查詢 |
| 社務管理「審核範圍」 | 待處理、全部、已處理三個按鈕 | 「審核範圍」下拉 |
| 一般退單、便當退單、發票人工處理、社務操作的原因選擇 | 多個常用原因及其他原因按鈕 | 有名稱的原因下拉；「其他原因」仍可填寫，完整理由保留顯示；選理由不會送出操作 |
| 一般結帳 `/checkout` 的配送通路 | 宅配／超商通路卡片 | 「配送通路」下拉，只列商品允許通路；正式配送開關維持原設定 |
| 團購詳情 `/groups/:id` 的取貨方式 | 合作社取貨／配送卡片 | 「取貨方式」下拉，未開放配送仍不可選 |
| 團購詳情的取貨地點 | 每個地點一張卡片 | 「取貨地點」下拉，摘要同步選定地點；地點載入失敗或無可用點時阻擋付款 |
| 團購詳情的配送通路 | 每個配送通路一張卡片 | 「配送通路」下拉，保留收件資料與報價流程 |
| 便當預訂 `/meals/:id` 的取餐時間 | 多個半小時時段按鈕 | 「預計取餐時間（台灣時間）」下拉，保留時段限制、網址與草稿 |
| 便當預訂的主食等單選群 | 多個純文字選項按鈕 | 至少三個有效選項、最多選一項且全部沒有照片時，改下拉；保留必選、加價／減價及選填清空 |
| 常見問題 `/help` | 團購取貨卡片直接顯示補充說明 | 集中於「各取貨點有哪些領取說明？」；展開才讀取，保留僅填說明而無地址的取貨點；同步更新選單操作說明 |

## 保留的操作

- 主要導航、一般／便當訂單分頁、今天／明天／本週／本月快捷選擇維持可見。
- 有照片的餐點選項、多選加購保留原介面。
- 查詢、付款、核准、拒絕、退款、匯出維持明確操作按鈕。
- 一般結帳的取貨方式與地點原本已是下拉，沿用。
- 未變更後端資料格式、計價規則、權限、正式配送開關或任何正式訂單。

## 驗證範圍

- 手機與桌面分類查詢、分頁重設、對帳、發票與會計匯出條件。
- 便當主食必選、價格、草稿還原、取餐時段、圖片與多選保留。
- 團購取貨地點摘要、空地點／讀取失敗、一般與團購配送通路。
- 退單與社務原因選擇、自訂理由、返回重開、確認後才送出。
- 窄螢幕、放大字級、選單邊界與欄位高度。

正式部署版本與驗收結果另記於使用者交付檔。
