# 循環便當與管理員股籍修正

日期：2026-09-17

## 需求與範圍

- 管理員可修正已認領社員及未認領名冊的股金／股數，社員仍看不到持股資料；股票號碼不再出現在管理表單或名冊卡片。
- 已認領名冊與會籍在同一筆交易同步；必填修改原因，記錄前後值及管理員。舊畫面版本回 409，不覆蓋其他管理員的修改。
- 修改帳面股籍不等於收款或退款：付款、繳費、退款、股籍日期及會籍資格完全不變。
- 便當可選日期、午晚餐、每 10 分鐘的取餐時間；後台循環排程預設週一至週六，保留手動建立和未有訂單場次的編輯。
- 午餐預設取餐 11:00–14:00、13:00 截單；晚餐 17:00–20:00、19:00 截單（Asia/Taipei）。取餐開始不再提前停止接單，截單後仍不可新增付款。
- 提案／社員會議拆為獨立頁面；新申請停收身分證字號及證件，保留基本資料與管理員審核。

## 股籍介面

`PATCH /v1/admin/member-roster/{entry_id}/shares` 與 `PATCH /v1/admin/members/{membership_id}/shares`，只供管理員使用。

輸入 `share_capital_amount`、`share_count`、`reason`、`expected_updated_at`；非負整數，原因不可空白，版本時間必須包含時區。鎖定順序為名冊 → 會籍，核對帳號與社員編號連結後才更新。一般社員 API 不回傳股籍或更新版本。
