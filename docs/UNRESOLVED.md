# 尚未處理與待確認事項

本文件只記錄尚未取得正式政策的事項。Sandbox 的暫定作法不得直接視為正式營運規則。

| 項目 | 狀態 | 決策者 | 阻擋範圍 | Sandbox 暫定作法 |
|---|---|---|---|---|
| 合作教育內容與完成方式 | 待確認 | 合作社／教授 | 教材、測驗、實體簽到及是否恢復入社門檻 | 本階段不實作，也不阻擋會籍啟用 |
| 真實證件收集的隱私告知 | 待法務確認 | 合作社 | 正式收件、使用目的、當事人權利及事件應變 | 只允許測試證件，畫面明示禁止真實資料 |
| 證件與社員資料保存期限 | 待政策確認 | 合作社 | 正式環境自動刪除與退社後保存 | Demo reset 刪除所有測試物件與資料 |
| 正式入社費與股金金額 | 待會議確認 | 合作社 | 正式入社付款 | 使用可調整的 500 元／1,000 元示範值 |
| 入社費、股金的會計與稅務 | 待會計確認 | 合作社會計 | 正式收據、發票及股金返還 | 只產生系統收據，不開電子發票 |
| 綠界正式物流合約與子類型 | 待簽約／測標 | 合作社 | 正式宅配、超商寄件及託運單 | 使用綠界 Stage 與後台 Sandbox 貨態推進 |
| 正式寄件人與倉儲資料 | 待確認 | 合作社 | 物流正式建單 | 由環境變數提供測試寄件資料 |
| 正式運費與免運門檻 | 待確認 | 合作社 | 正式結帳金額 | 超商 70 元、宅配 160 元、滿 1,500 元免運 |
| 實際校園、攤位與菜單 | 待會議確認 | 合作社／學校 | 正式便當場次 | 使用具名但不代表承諾的展示場次與菜單 |
