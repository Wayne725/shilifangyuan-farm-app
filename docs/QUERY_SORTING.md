# 查詢清單最新優先

日期：2026-11-06

## 需求與規則

訂單及各類紀錄查詢，預設最新資料在最前面。訂單依下單時間、報名依報名時間、收款依收款時間、徽章依取得時間；不是按取餐日、活動日或社員編號判斷新舊。當日資料會在歷史資料之前，同一天也是最近時間優先。

後端先排序再分頁，同一時間以 ID 固定次序，避免靜態資料翻頁時重複或漏列。既有日期、身分類型、付款狀態及文字篩選不變；目前查看中的訂單不會因列表刷新而被強制切走。新增資料時重新查詢可取得新的第一頁。

## 這次調整

| 範圍 | 調整 |
| --- | --- |
| 便當後台跨場次查詢、場次內訂單 | 改為下單時間由新到舊，排序完成後才分頁 |
| 顧客一般／便當訂單、後台場次清單 | 保留原有最新優先，補相同時間的穩定次序 |
| 訂單改量紀錄 | 最新修訂在前，原始異動紀錄與業務處理順序不變 |
| 財務日／週／月表 | 最新期間在前，金額及統計口徑不變 |
| 商品與活動付款／退款歷史 | 最新交易紀錄在前，退款及付款計算不變 |
| 我的活動報名 | 依實際報名時間排列，候補遞補仍依候補序號 |
| 入社繳款、既有社員後台名冊、合併社員帳冊 | 最新建立的紀錄在前；合併名冊先去重、排序，再分頁 |
| 通知、點數、徽章、願望、提案、共同購買、活動管理、入社申請、會籍、促銷 | 改最新優先或補相同時間的穩定次序 |

## 已符合，核對後保留

訂單營運主清單、財務訂單明細、發票查詢、退單查詢、出單工作紀錄、彙總列印批次、問題回報、會員搜尋、入社工作清單、對帳匯入批次與待連結訂單，原本已按紀錄時間由新到舊並有穩定次序。

## 依用途保留的順序

- 供餐日期／時段、近期活動、會議日期、廚房備餐優先序。
- 管理員設定的品項、取貨點、會議類別順序，以及公開商品／套組目錄。商品主檔的管理員清單已改建立時間最新優先，見 CATALOG_SALE_CONTROLS.md。
- 候補遞補、背景工作先後、退款鎖定順序。
- 送主管機關的社員名冊 CSV 仍依社員編號；畫面查詢使用最新優先。
- 對帳原始檔的列號、留言／審核時間線、測驗版本，以及銷量排名。

## 驗證

回歸測試涵蓋下單日與取餐日順序相反、今日與歷史資料、相同時間跨頁、一般／便當資料隔離、報名時間與活動時間相反、候補順序不變、合併名冊去重／篩選／匯出，以及財務金額不變。部署與正式站驗收結果另附本次交付紀錄。
