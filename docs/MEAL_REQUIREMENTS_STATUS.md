## 本次流程驗收

- 以桌面及 390px 手機測試時間帶入、同一場次改時間、返回與重整保留選餐、清空與無效時段。
- 財務沿用實際收款／完成退款基準；跨期退款在完成日入帳，重複付款列實際收退款，商品數量不重複。
- 財務範圍不含社員股金、入社費等非商品銷售款項。
- 開票及退款只能以供應商與系統查回結果判定，不以報表或 UI 更新代替真實交易結果。
