# 商品查詢與販售控制

日期：2026-11-06

## 需求與完成範圍

- 商品供應 → 商品主檔新增即時搜尋，支援商品名稱、SKU、產品編號與供應者；空白分隔的關鍵字需全部符合，不區分英文大小寫。
- 提供「全部／可販售／不可販售」按鈕與清除查詢，顯示符合數量與無結果狀態。
- 商品卡片可直接停止／恢復販售，更新期間停用操作、防止快速連點；失敗保留原狀態並顯示錯誤。
- 停售只修改 is_active；日常選購上架設定保留。恢復後沿用原設定。
- 管理員清單按建立時間由新到舊，公開目錄保留品類／名稱排序。

## 根因與衝突修正

原清單的「啟用」只是標籤，開關藏在編輯內且缺少搜尋。另重送原供應者 ID 時會因供應者已停用而阻擋儲存；現在允許保留原關係，仍禁止新選停用供應者。

編輯重新開啟時載入最新商品資料，取消會捨棄草稿。儲存只傳送相對開啟時有修改的欄位，避免改名稱／說明時將期間售出的庫存覆寫回舊值。

一般商品報價／新訂單原已檢查停售；共同購買套組缺少組內商品檢查，本次補上。新加入及增加數量鎖定商品後核對狀態，停售時只能減量；既有訂單保留原金額與品項，可依原訂單條件繼續付款，不會自動退單或退款。
