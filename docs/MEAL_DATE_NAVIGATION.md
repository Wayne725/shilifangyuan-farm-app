# 便當日期按鈕與分列排版

日期：2026-09-17

## 需求與範圍

將 `/shop` 便當預購的日期輸入框及前一天／今天／後一天改成直接可點的日期列；日期、餐別、餐點卡片不得重疊。沿用米色與深綠視覺，不改正式菜單、份數、取餐時段、付款或發票設定。

## 原因與修正

- 原頁沿用 `.market-subnav { margin: -12px 0 28px }`，第二列向上移入欄位 12px。1440px 和 390px 的 DOM 邊界測試均可穩定重現；僅將負間距改零的本機探針即通過，確認原因後還原共用樣式，避免影響其他頁面。
- 改用獨立 `MealDateNavigation`、`meal-booking-toolbar` 與日期／餐別間距；日期列、餐別、餐點各自一列，不採負間距。
- 日期顯示今天／明天、月日、星期及可預訂狀態，選中使用深綠底。手機僅日期列橫向滑動，頁面本身不水平溢出。
- 日期集合為今天至第 7 天（8 個日期）加所有未結束公開場次的取餐日期，保留超過 7 天手動場及昨日跨午夜場。
- 無場次週日顯示休息且停用；有手動場次的週日仍可選。無場次的其他日期顯示尚未開放，不捏造菜單。
- 餐別以全部／午餐／晚餐按鈕篩選。已截止仍可查看，但不改原有訂購／付款限制；無場次餐別停用。
- 可預訂狀態同時核對時間、有效菜單、剩餘份數及未來取餐時刻；未到時間、已截止、售完與菜單待公告分開顯示。

## 驗證

- 原碼幾何驗證：桌面與手機 2 項皆失敗，重疊均為 12px。
- 新版日期列 5 項測試通過，控制項零重疊、日期與餐別列至少間隔 24px、頁面無水平溢出。
- 完整瀏覽器 64／64、前端與契約 45／45、型別檢查及正式建置通過。
- 狀態 helper 13 項用真實 TypeScript 轉譯後執行，包含精確截單、售完、空／停用菜單、跨午夜、台灣時區、週日及遠期手動場；UTC 與洛杉磯時區亦通過。
- 1440px／390px 截圖已目視。手機全頁截圖一度有離屏圖片繪製瑕疵，獨立卡片截圖與 decode 後量測顯示圖片 240px、內容緊接，未對正常卡片加補丁。
