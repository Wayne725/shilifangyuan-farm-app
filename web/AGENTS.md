# 前台介面文案約定

- 補充說明、背景解釋、操作後提醒及領獎等延伸資訊，統一放在 `/help` 的常見問題。
- 不在按鈕、欄位旁、欄位下方或卡片尾端常駐顯示上述提醒，也不以 tooltip 或隱藏樣式替代移除。
- 操作區保留欄位名稱、選項名稱、價格、必選規則，以及當下的驗證錯誤、阻擋原因與操作結果。
- 移除說明段落時，同步檢查 `aria-describedby`，避免指向不存在的元素；可將其連到實際顯示的驗證錯誤。
- 沿用現有米色、深綠、黃色中英小標及字體風格。

# 後台操作欄位

- 管理員的處理原因、核對說明、備註及供應者審認過程均可留空；不要以 `required`、最小字數或提交守衛要求非空，保留原有字數上限。
- 原因欄位標籤以 `<OptionalMark />` 標示「（選填）」，文字由 CSS `::after` 產生，不計入 label 文字，`getByLabel` 與無障礙名稱維持原欄名；可選預設原因，也可自訂或清空。
- 操作確認、收退款金額、權限、資料版本、可操作狀態、名冊核對與必要勾選仍須驗證。理事會決議依據與會議決議正文不屬於操作備註。
- 原因留空時，紀錄卡片省略空的原因列；仍保留操作人員、時間及結果。顧客端表單依各自的業務規則驗證。
